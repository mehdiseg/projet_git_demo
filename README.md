# Exercice Git : premiers commits et collaboration

Petit dépôt d'exercice du BTS SIO pour apprendre le travail collaboratif avec **Git** et **GitHub**.

## Ce que l'historique montre

1. Création du dépôt (`Initial commit`).
2. Ajout d'une page `index.html`.
3. Récupération et intégration d'une modification faite par un collègue : un paragraphe ajouté à `index.html`.

## Notions travaillées

- Le cycle `git add`, `git commit`, `git push`.
- Récupérer les changements d'un collègue et les intégrer à son propre dépôt.
- Lire l'historique d'un projet à plusieurs (`git log`).

## Contenu

| Fichier | Rôle |
|---|---|
| `index.html` | Page de test |
| `styles.css` | Feuille de style (vide) |

Le dépôt sert uniquement d'exercice : il n'y a pas de code à exécuter.
